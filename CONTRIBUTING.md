# Contributing

PROJECT BLACKSHEEP Sensors is in early hardware-development and architecture work.

The current focus is:
- ESP32-C5 board bring-up
- passive Wi-Fi sensing on 2.4 GHz and 5 GHz
- sensor attribute definition
- local aggregation and bounded sensor output
- later integration with the BLACKSHEEP control board and ARGUS REDLINE

Interfaces and firmware structure are not yet stable.

Before opening a pull request for major changes, open an issue or discussion first so work does not collide with active architecture development.
