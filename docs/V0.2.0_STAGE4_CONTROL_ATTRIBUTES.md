# v0.2.0 Stage 4 — Control Attributes

## Objective and authorities

Stage 4 determines which Sequence Control and Frame Control protocol facts are
safely available. It follows IEEE 802.11-2020 MAC-header definitions, the
public Linux `ieee80211.h` FC/sequence masks and header-length implementation,
the installed ESP-IDF 5.5.4 public receive definitions, and the Stage 2 layout
descriptor. Standard layout and bit meaning are distinct from BLACKSHEEP's
bounded characterization; no behavioral inference is added.

## Parser contract

`wifi_control_attributes_t` contains an inherited parse status plus explicit
validity for the FC facts and Sequence Control. Retry, More Fragments, and
Protected are copied as booleans only when the complete two-byte FC is valid.
Zero is never used as an unavailable sentinel.

Sequence Control is read explicitly little-endian at bytes 22–23 only for a
descriptor-proven management or data layout. The extraction is:

- fragment number: bits 0–3, range 0–15;
- sequence number: bits 4–15, range 0–4095.

The common management and data headers contain Sequence Control. Addr4, QoS
Control, and HT Control occur later and therefore do not move it. None of the
Stage 2-supported control layouts contains Sequence Control, so both sequence
and fragment validity remain false for Control Wrapper, BAR, compressed BA,
PS-Poll, RTS, CTS, ACK, CF-End, and CF-End+CF-Ack.

Sequence Control can become valid at the exact 24-byte boundary even when a
later optional portion of a QoS/Addr4/HT layout remains truncated. No partial
16-bit field becomes valid. Reserved, unsupported, extension, malformed, or
descriptor-unproven contexts never guess Sequence Control availability.

## Semantic limits

Retry indicates the transmitter's retransmission protocol fact. It does not
prove BLACKSHEEP saw an original, identify a duplicate in this event stream,
measure loss, count retransmissions, or establish link quality. There is no
deduplication or per-transmitter history.

More Fragments and fragment number are reported independently. No fragments
are buffered, correlated, reconstructed, or reassembled.

Protected indicates the protected-frame protocol bit. It does not establish
WPA2, WPA3, a cipher, keys, decryptability, content, or security state. No body
is inspected and no payload or key handling exists.

A sequence number is scoped by protocol context and is not a globally unique
frame identifier, device identity, persistent key, or cross-transmitter value.

## Host validation

The strict-warning host suite passed **844,876 assertions**, including 100,000
deterministic randomized inputs of lengths 0–40. MinGW still lacks `libasan`
and `libubsan`; the existing runner detected that unchanged limitation and ran
the identical suite without sanitizers.

Golden coverage includes all eight combinations of Retry/More-Fragments/
Protected; sequence boundaries 0, 1, 2047, 2048, 4094, and 4095; fragment
boundaries 0, 1, 7, 8, 14, and 15; every supported management subtype; all 16
data subtypes with all four DS combinations; QoS, Addr4, and HT-bearing forms;
and Sequence Control absence for every supported control subtype. Lengths below
the complete field, the exact boundary, later optional truncation, null input,
unsupported/reserved layouts, and randomized invariants all passed. Stage 1–3
assertions remain enabled.

## Controlled physical method

C5 #1 first observed a quiet channel and correctly reported no callbacks. It
was then rerun using the existing ignored disposable owned-C5 transmitter on
fixed 2.4 GHz channel 1. That transmitter emitted a finite eight-second burst
of ordinary three-address data frames and let the ESP-IDF transmit path assign
Sequence Control. This provided independently controlled traffic without
retaining identifiers or bodies. The transmitter was removed and C5 #2 was
restored to its sensor image afterward.

C5 #2 observed an owned encrypted WLAN on fixed US non-DFS 5 GHz channel 36.
Ordinary WLAN traffic supplied changing Sequence Control and protected data.
No encrypted body was inspected. A Retry bit appeared naturally; no distance,
orientation, interference, jamming, deauthentication, or authentication
manipulation was used. Consequently the bounded controlled degraded-link Retry
comparison is **NOT PERFORMED / EXPERIMENTAL**, and the single observed bit is
not treated as link or retransmission-history evidence.

### C5 #1 — 2.4 GHz

USB identity ended `9E:88`; the rediscovered temporary port was COM6. Upload
hash verification, ESP-IDF second-stage boot, revision 1.2, QIO/80 MHz, 32 MB
flash, 8 MB PSRAM test, 2.4-GHz-only mode, and fixed channel 1 passed.

The controlled window produced 749 callbacks/enqueues/processed frames, zero
drops, and high-water 1. All 749 parsed successfully with class agreement.
Sequence Control was valid 749 times with observed range 1–765. Fragment mask
was `0x0001` (fragment 0 only). Retry was 0/749 set/clear, More Fragments 0/749,
and Protected 0/749, as expected for this unprotected controlled raw burst.
Parser failures were zero. Callback timing was 6/47/6 microseconds minimum/
maximum/average. Shutdown drained cleanly, READY returned, and ten heartbeats
were observed.

### C5 #2 — 5 GHz

USB identity ended `AC:6C`; the rediscovered temporary port was COM7. Upload
hash verification, the same hardware baseline, manual US context, 5-GHz-only
mode, and fixed non-DFS channel 36 passed.

The window produced 170 callbacks/enqueues/processed frames, zero drops, and
high-water 1. All 170 parsed successfully with class agreement. Sequence
Control was valid 170 times with observed range 1–3957. Retry was 1/169
set/clear, More Fragments 0/170, and Protected 29/141. The fragment mask was
`0x2001`, representing observed numeric values 0 and 13; because this was not a
controlled fragmentation experiment and More Fragments was never set, no
fragmentation conclusion is made. Parser failures were zero. Callback timing
was 6/51/6 microseconds. Shutdown drained cleanly, READY returned, and eleven
heartbeats were observed.

Physical fragmentation and controlled degraded-link Retry remain **NOT
OBSERVED / EXPERIMENTAL**. Their parser behavior is host validated.

## Privacy, unresolved questions, and acceptance

Only aggregate counters and numeric protocol ranges/masks were printed. No MAC,
SSID, payload, packet capture, serial log, per-device sequence history, fragment
body, or protected body is retained. No Stage 5 RF characterization was begun.

The practical frequency of fragmentation and the behavior of Retry in a
controlled degraded-but-nondisruptive link remain unresolved. Stage 4
acceptance is **PASS** because exact host decoding, bounded dual-band physical
availability, protected-frame evidence, honest Experimental/unobserved status,
clean performance, and all regressions are established without semantic
overreach.
